# Cloud Resume Extraction

**PDF resumes → structured JSON** via a **FastAPI** service: PyMuPDF / pdfminer / OCR → preprocessing → **Hugging Face BERT + LoRA NER** (with heuristic hybrid) → validated profile JSON.

## Quick start

1. Python 3.11+, create a venv at repo root (e.g. `python -m venv env`).
2. Install: `pip install -r requirements.txt` (Windows: `uvloop` is skipped automatically).
3. Put model weights under `models/resume-ner/final/` (with `merged/` and `label_map.json` after training/export).
4. Run API from **`code/`**:

```powershell
cd code
$env:PYTHONPATH = "."
$env:USE_MOCK_INFERENCE = "0"
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

5. Open **http://127.0.0.1:8000/docs** and try `POST /extract` with a PDF.

For training, evaluation, Docker, AWS, Postman, and troubleshooting, read **[DOCS/PROJECT_MANUAL.md](DOCS/PROJECT_MANUAL.md)** (full project documentation).

## Repository layout (short)

| Path | Role |
|------|------|
| `code/app/` | FastAPI app (`main.py`, `routers/extract.py`, services) |
| `code/scripts/` | Train, eval, parser benchmark, dataset audit |
| `models/resume-ner/` | LoRA checkpoints and `final/` export |
| `DOCS/` | Architecture, API, deployment, alignment with course docs |
| `manifests/` | Dataset inventory and split CSVs (committed) |
| `reports/` | Metrics JSON (generated by eval scripts) |

`dataset/` is gitignored (local corpus).
